# 설비 (The Apparatus) — 2D Action

점수나 평가 없이 반복되는 일상과 침묵 속의 선택을 그리는 2D 픽셀 액션 게임입니다. 플레이어는 번호표를 단 주인공이 되어 13개의 장을 지나가며, 자동으로 움직이는 설비를 상대하고 생존을 위한 선택에 직면합니다. 골목에서 마주치는 인물을 살려 보내거나 죽이는 선택은 마지막 장의 연출에 반영됩니다.

## 주요 특징

- **13장으로 이어지는 이야기**: 거리와 보호소, 뒷골목, 부엌, 옥상 등을 배경으로 이야기가 진행됩니다.
- **타이밍 기반 액션**: 설비의 공격 주기를 살피고, 공격을 피하거나 공격 가능한 틈에 반격합니다.
- **선택과 결말 연출**: 조우에서 내린 선택이 마지막 장면에 영향을 줍니다.
- **인물록**: 주요 인물 6명의 역할과 정보를 확인할 수 있습니다.
- **픽셀 렌더링과 자체 사운드**: 320×180 캔버스를 정수 배율로 확대하며, 효과음은 Web Audio API로 생성합니다.
- **키보드 및 모바일 터치 조작**을 지원합니다.

## 시작하기

### 요구 사항

- Node.js 및 npm

### 설치 및 실행

```bash
npm install
npm run dev
```

터미널에 표시되는 로컬 주소로 브라우저에서 접속합니다. 개발 서버는 기본적으로 `http://localhost:3000`에서 실행됩니다.

### 빌드 및 확인

```bash
npm run build
npm run preview
```

타입 검사는 다음 명령으로 실행합니다.

```bash
npm run lint
```

## 조작법

| 동작 | 키보드 |
| --- | --- |
| 이동 | ← / → 또는 A / D |
| 점프 | Space, ↑ 또는 W |
| 공격 | Z |
| 구르기 | X |
| 대화 넘기기 / 선택 확정 | Z, Space 또는 Enter |
| 조우 선택 변경 | ← / → 또는 A / D |
| 인물록 열기/닫기 | Esc |

화면 위쪽 툴바에서 소리를 끄거나 켜고, 게임 화면 배율을 바꾸거나 처음부터 다시 시작할 수 있습니다. 모바일 화면에서는 표시되는 터치 버튼을 사용하세요.

## 프로젝트 구조

```text
.
├── public/assets/characters/  # 인물 이미지
├── src/
│   ├── App.tsx                # 게임 루프, 장면/전투 로직, UI 및 렌더링
│   ├── index.css              # 전역 스타일 및 픽셀 렌더링 설정
│   └── main.tsx               # React 진입점
├── index.html
├── package.json
├── tsconfig.json
└── vite.config.ts
```

게임 화면과 시뮬레이션은 `src/App.tsx`에 구현되어 있으며, 60Hz 고정 타임스텝으로 업데이트됩니다. 화면은 HTML Canvas에 그려지고 대화 및 인물록 UI는 React로 구성됩니다.

## 기술 스택

- React 19, TypeScript
- Vite
- HTML Canvas 및 Web Audio API
- Tailwind CSS 4
- lucide-react 아이콘
